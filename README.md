# Portafolio de Josué Mejía

Portafolio personal de Josué Mejía, desarrollado con Next.js (App Router), React, TypeScript, CSS Modules, ESLint y Lucide React.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## ESLint

```bash
npm run lint
```

## Compilación de producción

```bash
npm run build
```
